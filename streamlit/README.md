# Streamlit Tutorials & Applications

This directory contains Streamlit tutorial chapters and hands-on applications.

## Chapters & Projects

- **`chp_1.py`**: Getting started with Python and starter script.
- **`chp_2.py`**: **Age Calculator App** - Interactive Streamlit application to calculate real age in years, months, and days based on the user's Date of Birth.
- **`chp_3.py`**: Streamlit and **Pandas** data manipulation.

## Installation

Using `pip`:
```bash
pip install -r requirements.txt
```

Or using `uv`:
```bash
uv sync
```

## Running the Applications

Run any chapter with Streamlit:
```bash
streamlit run chp_2.py
```
